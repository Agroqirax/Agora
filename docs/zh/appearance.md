# 外观

打开**设置 → 外观**调整 Agora 的视觉与生成内容展示方式。

## 主题与字体

- 跟随系统或选择亮色/暗色模式与可用配色。
- 使用系统字体、Agora 内置字体或导入自定义字体。
- 在设备与构建支持时启用动态取色。

## 聊天展示

- 显示或隐藏详细 Token 用量。
- 以卡片或 Bottom Sheet 展示思考片段。
- 以时间线、分组或紧凑形式展示思考和工具活动。
- 卡片模式下可自动展开当前活跃分组。
- 启用或关闭触觉反馈。

## 动效与效果

模糊只作用于聊天列表顶部工具栏下方区域。**减少动效**会取消或缩短已支持的转场与装饰动效，不会改变消息生成或数据行为。
