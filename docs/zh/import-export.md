# 导入与导出

打开**设置 → 导入与导出**迁移或备份 Agora 数据。

## Agora 归档

`.agora` 是带版本的 ZIP 归档，当前格式版本为 4。按所选类别可包含：

- 对话、运行、消息、任务、循环及相关图数据
- 附件、工具媒体和草稿媒体
- 记忆与系统提示词
- 应用设置和导入的自定义字体
- 仅在明确选择时包含的 API Key 与其他机密

!!! warning "保护包含机密的归档"
    机密在归档内部未加密。请像保护原始凭据一样存储和传输该文件。

导入冲突可选择合并、替换或跳过。

## 第三方导入与自动备份

可直接导入 ChatGPT 和 Claude 导出 ZIP。Claude 的附件记录可能只有元数据而没有原文件。WorkManager 可按所选目录、周期、类别和保留策略进行自动备份；Android 后台策略会影响实际时机。
