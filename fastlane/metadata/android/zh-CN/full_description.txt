Agora 是开源 BYOK Android LLM 客户端。对话保存在设备上，模型请求由设备直接发送到你配置的提供商或端点。

功能：
* 九类提供商：OpenAI、Anthropic、Google Gemini、DeepSeek、通义千问/DashScope、OpenRouter、Groq、Ollama 和本地 GGUF；自定义端点支持 OpenAI 兼容、Google 与 Anthropic 协议
* 树形对话：编辑、重新生成和切换备选分支
* Token 预算上下文与非破坏式 Compact 胶囊
* 代理工具：网络搜索、记忆、历史对话 RAG、图片生成、MCP、任务/循环与远程 Shell/文件
* 持久 Conch 任务与 SSH；配置 API Key 时 Conch 使用应用层加密
* llama.cpp 设备端推理与本地嵌入
* 带版本的 .agora ZIP 导入/导出、ChatGPT/Claude 导入和自动备份
* Material 3 界面，可配置思考/工具展示、字体、触觉，支持 12 种界面语言

只有使用对应功能时，数据才会发送给外部提供商或工具。崩溃后匿名诊断报告只保存在本地，并仅在用户下次启动明确确认时发送；准确网络目的地与备份安全边界请查看应用/用户手册的隐私文档。
